# EV2 Minería de Datos (TI3061) · Grupo 6

Limpieza, transformación y validación del dataset de pacientes en R.

Integrantes: Benjamín Vidal, Amanda Cáceres, Abraham Grundt y Benjamín Cifuentes.

## Cómo correrlo

1. En RStudio: *Session > Set Working Directory > Choose Directory…* y elegir esta carpeta.
2. Instalar dplyr una vez: `install.packages("dplyr")`.
3. Ejecutar `Grupo6_script_limpieza_pacientes.R` completo.

## Archivos

- `Grupo6_script_limpieza_pacientes.R`: script completo, de la carga a la exportación.
- `scripts/01` a `04`: el mismo script separado por etapa.
- `data/raw/pacientes.csv`: dataset original.
- `data/processed/pacientes_final.csv`: dataset final (912 filas).
